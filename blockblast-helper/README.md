# Block Blast Helper (Android)

Помощник для Block Blast: прямо поверх игры показывает, куда и в каком порядке ставить три фигуры.

APK самой игры не меняется. Приложение записывает экран (MediaProjection), распознаёт поле 8×8
и фигуры в лотке, перебирает все порядки и позиции (до 3! × 64³ вариантов) и рисует контуры
поверх игры (`TYPE_APPLICATION_OVERLAY`).

## Установка

1. Скачайте APK: вкладка **Actions** → **Build Block Blast Helper** → последний запуск → **Artifacts**.
2. Установите (разрешите установку из неизвестных источников).
3. В приложении: «Разрешить поверх окон» → «Запустить» → разрешить запись **всего экрана**.
4. Откройте Block Blast. При первом запуске появится разметка: зелёную рамку совместите с полем,
   оранжевую — с зоной трёх фигур, нажмите «Сохранить».

## Подсказки

- Контур **1** (сплошной, зелёный) — первый ход; **2** и **3** (пунктир) — следующие.
- Те же номера показаны над фигурами в лотке.
- «Ходов нет» — ни одна фигура не помещается. Если фигуры или ходы не нашлись, тот же кадр
  автоматически перепроверяется в контрастном режиме (пометка «контраст»).
- Кнопка **⟳** (под «BB») — ручной анализ: кадр разбирается в контрастном режиме (порог подбирается
  по самой картинке), ходы считаются принудительно, и на 6 секунд показывается чёрно-белая схема
  распознанного поля и фигур — по ней видно, где приложение ошиблось.
- Кнопка **BB**: нажать — вкл/выкл, удерживать — разметка заново, тащить — переместить.
  Не держите её над полем или фигурами — она попадёт в распознавание.
- Размер фигур в лотке приложение выучивает само за первые несколько наборов фигур
  (по одному кадру квадрат 2×2 неотличим от 1×1), поэтому в начале игры возможны ошибки.
- Кнопка **Снимок** в уведомлении сохраняет кадр с тем, что распознано, в `Pictures/BBHelper` —
  пригодится, если подсказки ошибаются.

## Как выбирается ход

1. Перебираются все порядки и позиции трёх фигур (повторяющиеся позиции отсекаются).
2. Итоговые поля оцениваются быстро: свободное место, «рваность» краёв (стены считаются занятыми),
   одиночные дыры, есть ли место под 2×2; плюс очки за очистки и комбо.
3. Лучшие 96 переоцениваются по тому, какая доля всего набора фигур Block Blast на них ещё помещается.
4. Лучшие 16 проверяются заглядыванием вперёд: на 64 случайных будущих наборах из трёх фигур
   считается, сколько из них удастся поставить целиком.

Комбо отслеживается по экрану: какая фигура ушла из лотка и были ли очищены линии.
Серия держится, если очищать линии хотя бы раз за 3 постановки, и решатель это учитывает.

Веса подобраны самоигрой в симуляторе (`core/Simulator.kt`) со случайными фигурами из полного набора.
Среднее время жизни до проигрыша в симуляции: ~140–170 наборов фигур у первой версии,
~370 у текущей. Симулятор строже игры: фигуры в нём полностью случайные.

## Сборка

```
cd blockblast-helper
gradle testDebugUnitTest assembleRelease
```

Нужны JDK 17 и Android SDK 34. Логика (`core/Solver.kt`, `core/Vision.kt`) — чистый Kotlin
без зависимостей от Android, покрыта тестами в `app/src/test`.
