GitHub-токен

Нужен один раз, чтобы панель могла публиковать изменения в репозиторий. Создайте fine-grained token в настройках GitHub с доступом только к репозиторию AVAILOFF/TUOverlays и правом Contents: Read and write. Токен хранится только в этом браузере (localStorage) и никуда, кроме api.github.com, не отправляется.
